# 同梱した公式プロバイダーアイコン

`assets/icons/providers/` は、公式配布ZIPから構成図で頻出するSVGだけを選んだキュレーションです。ZIP全体ではありません。

- AWS: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) — `Icon-package_04302026...zip`
- Azure: [Azure Icons](https://learn.microsoft.com/en-us/azure/architecture/icons/) — `Azure_Public_Service_Icons_V24.zip`
- Google Cloud: [Google Cloud product icons](https://cloud.google.com/icons) — `core-products-icons.zip`

公式アイコンはブランド資産です。generic namespaceの代わりに使用せず、製品を実際に表すノードへ `provider` を付けてください。各ファイルの出典・SHA-256・利用文脈は `assets/icons/manifest.json` に記録しています。
