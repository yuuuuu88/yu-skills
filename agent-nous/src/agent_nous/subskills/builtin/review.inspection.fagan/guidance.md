# Software Inspection

## Core

Separate preparation, defect detection, recording, correction, and follow-up; identify reproducible defects before solution debate.

## Source

- Originator: Michael Fagan
- https://research.ibm.com/publications/advances-in-software-inspections

## Output evidence

Record why this method applies, the concrete check performed, evidence found, and any limitation. Do not claim formal compliance unless the task explicitly requires and demonstrates it.
