# Plain Japanese Review

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

読者が一度で判断できるよう、目的、主体、条件、操作、結果を短く具体化する。専門語は必要性と説明を確認する。

## 判定規則

丁寧さや短さを目的化せず、意味・責任主体・例外を保ったまま理解コストだけを下げる。
