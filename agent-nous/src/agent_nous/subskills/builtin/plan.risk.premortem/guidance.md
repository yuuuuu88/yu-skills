# Pre-mortem Risk Review

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

成功した後ではなく失敗した後を想像し、起こり得る失敗を原因・兆候・予防策・発生時の対応へ分解する。

## 判定規則

最も深刻で早期検知できない失敗を優先し、各リスクに所有者・観測方法・回避または縮退策を置く。
