# Nous Pilot design documents

## Responsibility

Current product and technical design. Progress, checkpoints, and unresolved execution work belong in `docs/plans/`.

## Documents

- [architecture/](./architecture/): system structure and runtime boundary
- [features/](./features/): vertical feature slices
- [contracts/](./contracts/): typed interfaces and evidence contracts
- [cross-cutting/](./cross-cutting/): security and observability
- [decisions/](./decisions/): ADRs

## Design principles

- source-of-truth documents are versioned and linked
- contract changes require compatibility validation
- external research is evidence, not an automatic instruction
- design changes are reflected in the plan before implementation proceeds
