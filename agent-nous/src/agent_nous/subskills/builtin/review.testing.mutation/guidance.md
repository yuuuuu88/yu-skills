# Mutation Testing

## Core

Inject small faults into high-risk logic and classify surviving mutations as test gaps or equivalent changes.

## Source

- Originator: Richard DeMillo, Richard Lipton, and Frederick Sayward
- https://doi.org/10.1109/MC.1978.1646571

## Output evidence

Record why this method applies, the concrete check performed, evidence found, and any limitation. Do not claim formal compliance unless the task explicitly requires and demonstrates it.
