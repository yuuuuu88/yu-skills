# Application Security Verification Standard

## Core

For applicable web security concerns, record requirement ID, method, evidence, result, and reason for omissions.

## Source

- Originator: OWASP Foundation
- https://owasp.org/www-project-application-security-verification-standard/

## Output evidence

Record why this method applies, the concrete check performed, evidence found, and any limitation. Do not claim formal compliance unless the task explicitly requires and demonstrates it.
