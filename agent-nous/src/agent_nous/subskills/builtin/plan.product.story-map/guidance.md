# Outcome Slice Mapping

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

利用者の目的から行動を並べ、最小の価値提供に必要な薄い縦切りを選ぶ。機能一覧をそのまま計画にしない。

## 判定規則

各sliceに利用者の結果、受入条件、未対応範囲を持たせ、依存関係と検証可能性で順序を決める。
