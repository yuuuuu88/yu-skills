# 文書の型と構成

## 主文書型を1つ選ぶ

| 型 | 読者の目的 | 主な構成 |
|---|---|---|
| チュートリアル | 学びながら動かす | 到達点、前提、手順、成功確認 |
| How-to | 作業を完了する | 目的、適用条件、手順、失敗時の対応 |
| リファレンス | 正確な仕様を調べる | 定義、項目、値、制約、例 |
| 説明 | 仕組みや理由を理解する | 背景、全体像、関係、判断理由、制約 |

主文書型に合わない情報は、削除、別文書への移動、補足への移動を検討する。

## 標準構成

### 手順文書

1. 何ができるか
2. 対象読者と前提
3. 完了条件
4. 最短の手順
5. 分岐や例外
6. 失敗時の対応
7. 参照元

### 仕組みの説明

1. まず結論
2. 用語
3. 全体像
4. 各要素の役割
5. データや処理の流れ
6. 制約と判断理由
7. 詳細へのリンク

### 仕様・リファレンス

1. 対象範囲
2. 用語と定義
3. 入力
4. 出力
5. 設定値・制約
6. エラーや境界条件
7. 例

## 複数文書を統合する場合

1. 読者、目的、正確性、更新頻度を比較する。
2. 重複する説明を1か所へ集める。
3. 正本を決め、他の文書からリンクする。
4. 目的が違う内容は無理に混ぜず分割する。
5. 古い説明は根拠を確認して削除する。
