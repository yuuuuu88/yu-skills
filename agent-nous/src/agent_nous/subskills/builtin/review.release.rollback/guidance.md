# Release and Rollback Review

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

リリース前に観測、段階投入、停止条件、ロールバック、データ復旧、担当者を確認する。

## 判定規則

成功経路だけでなく失敗時の最短安全経路を実行可能なvalidationとして提案する。
