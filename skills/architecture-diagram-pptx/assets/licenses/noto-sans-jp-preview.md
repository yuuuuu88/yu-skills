# Noto Sans JP preview font

The preview renderer may use Noto Sans JP / Noto Sans CJK JP so Japanese text
is visible in the review PNG. The font is not embedded into the generated
PPTX; the receiving PowerPoint environment supplies its own presentation font.

- Package used by the reproducible preview setup: `@fontsource/noto-sans-jp` 5.3.0
- License: SIL Open Font License 1.1 (OFL-1.1)
- Source: https://www.npmjs.com/package/@fontsource/noto-sans-jp
- Alternative system font source: Debian/Ubuntu `fonts-noto-cjk`
