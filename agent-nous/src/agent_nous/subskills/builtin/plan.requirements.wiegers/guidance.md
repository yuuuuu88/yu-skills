# Software Requirements

## Core

Separate business, user, functional, quality requirements, and constraints; link each to source and acceptance evidence.

## Source

- Originator: Karl Wiegers and Joy Beatty
- https://www.processimpact.com/pubs.html

## Output evidence

Record why this method applies, the concrete check performed, evidence found, and any limitation. Do not claim formal compliance unless the task explicitly requires and demonstrates it.
