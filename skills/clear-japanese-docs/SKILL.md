# 分かりやすい日本語Markdown

## 基本方針

読者が「自分に関係するか」「何を知ればよいか」「次に何をすればよいか」を迷わず判断できる文書を作る。短くするだけでなく、必要な前提と正確さを保つ。

## 実行手順

1. 入力文書、関連文書、コード、設定、参照リンクを読む。
2. 主な読者、目的、前提知識、適用範囲を決める。
3. [文書の型と構成](references/document-shape.md)から主文書型を1つ選ぶ。
4. 結論、前提、概要、最短経路、詳細、注意点の順に並べる。
5. [日本語の書き方](references/writing-style.md)に従って整える。
6. 文章だけでは追いにくい関係や流れがある場合は、[Mermaidの使い方](references/mermaid-guide.md)を読み、図を本文の近くに置く。
7. 既存文書の編集では、[破壊的な再構成](references/destructive-rewrite.md)を適用する。
8. [品質チェックリスト](references/quality-checklist.md)で確認する。

## 標準の出力構成

不要な節は省く。ただし、必要な前提は隠さない。

1. タイトル
2. まず結論
3. 前提
4. 概要
5. 全体像または流れ
6. 本文
7. 用語
8. 注意点・制約
9. 次にすること
10. 参照元

## 既存文書を編集したとき

完成したMarkdownを先に出し、その後に次を短く報告する。

- 構成をどう変えたか
- 削除・統合した内容
- 保留した点、確認が必要な点

事実を創作しない。根拠が確認できない情報、矛盾する情報、安全性や法的意味が変わる注意書きは黙って処理しない。
