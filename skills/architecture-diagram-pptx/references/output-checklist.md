# 納品前チェックリスト

## 内容

- [ ] タイトルが図の問いを表している
- [ ] 読者、目的、範囲、図種、抽象度が分かる
- [ ] 外部/内部、信頼境界、ネットワーク境界が区別されている
- [ ] ノード名、役割、製品名、経路ラベルが事実と一致する
- [ ] `relation`（データフロー、依存、制御、監視、メッセージ、応答など）が明示され、矢印方向を一文で読める
- [ ] 矢印の方向、同期/非同期、認証/暗号化の意味が凡例で分かる
- [ ] 推測、要確認、未確定の経路を明示している

## 見た目

- [ ] 同種ノードの色・形・線幅・文字サイズが統一されている
- [ ] グリッドに整列し、左右/上下の余白が揃っている
- [ ] 主経路の箱が斜めに並ばず、通常の箱が縦長になっていない
- [ ] コネクタが水平・垂直で、意図しない交差・迷路・折れがない
- [ ] 線の交差、線とラベルの重なり、ノードの重なりがない
- [ ] 経路ラベルは自分の矢印から0.32インチ以内で、横並びノード間の空き幅に収まっている
- [ ] ノード内のタイトルと役割説明が重ならない。高密度図では役割説明を省き、短いタイトルを優先している
- [ ] 親子でない境界同士が重ならず、最低0.12インチの隙間がある
- [ ] コネクタが境界の外周を長くなぞっていない
- [ ] `visual_qa.py` の衝突エラーが0件で、SVG/PNGプレビューを確認した
- [ ] 小さすぎる文字、長すぎるラベル、過剰な装飾がない
- [ ] 色以外の形・線種・ラベルでもカテゴリを区別できる
- [ ] 凡例、更新日、版、出典がある

## 編集性

- [ ] 図全体が一枚の画像ではない
- [ ] ノード、境界、テキスト、コネクタ、アイコンを個別に選択できる
- [ ] line shapeがノード近くの端点から始まり、折れ線の最後だけに矢印がある
- [ ] PPTXを開いた後にノードを動かした場合、必要な線の端点を手動で再調整できる（自動再接続は前提にしない）
- [ ] アイコン画像と製品名テキストが分離している
- [ ] アイコンがノードの主役として十分な大きさで、四角と文字だけに見えない
- [ ] `assets/icons/manifest.json` の解決結果とSHA-256を確認した
- [ ] 元の仕様JSON/生成ソースが残っている

## 技術検証

- [ ] `python3 scripts/check_diagram_spec.py diagram.json --layout --semantics` が成功した
- [ ] `python3 scripts/run_visual_fixtures.py` で正常系と、ラベル距離・境界間隔・境界線沿いコネクタを含む崩れ検知ケースを確認した
- [ ] `python3 scripts/review_diagram.py diagram.json --strict` で仕様・visual QA・プレビュー・PPTX検証を一括確認した
- [ ] `python3 scripts/validate_pptx.py output.pptx` が成功した
- [ ] OOXMLのCRC、XML、内部relationship target、負のtransformを検査した
- [ ] PowerPointまたはLibreOfficeで開ける（実施した場合のみ報告）
- [ ] 目視確認をしていない場合、その制約を報告した
- [ ] 使用した外部アイコンの出典・許諾メモがある
