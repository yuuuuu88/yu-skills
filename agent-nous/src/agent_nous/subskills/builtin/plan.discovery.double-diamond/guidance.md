# Double-Diamond Discovery

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

不確実性の発見と収束を分け、問題の探索・定義・解決案の探索・検証を別々に記録する。各段階で捨てた仮説と次に得る証拠を明示する。

## 判定規則

探索と収束を混ぜず、問題定義が証拠で固定されるまで解決策を確定しない。
