# Contextual Japanese Register

このガイダンスは公開仕様・実践知をNous向けに独立再設計したもの。外部skillの本文、script、server、installerは同梱しない。

## 運用

敬語・丁寧さを一律置換せず、相手、場面、内外関係、依頼の目的に合うかを確認する。

## 判定規則

丁寧化で責任主体や条件を曖昧にしない。不要な敬語や過剰なへりくだりも修正候補にする。
