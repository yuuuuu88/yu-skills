# 品質チェックリスト

## 読者と内容

- [ ] 主な読者が1人に定まっている。
- [ ] 目的と適用範囲が冒頭で分かる。
- [ ] 必要な前提条件が後ろに隠れていない。
- [ ] 主文書型が1つに定まっている。
- [ ] 事実、推測、未確認事項が区別されている。

## 読みやすさ

- [ ] 結論または到達点が先にある。
- [ ] 1段落1メッセージになっている。
- [ ] 専門語が最初に説明されている。
- [ ] 手順は番号付き、比較は表になっている。
- [ ] 重複、抽象表現、目的外の説明が残っていない。
- [ ] 読者が成功したか判断できる。

## Mermaid

- [ ] 図は理解を助ける目的で使われている。
- [ ] 図種が内容に合っている。
- [ ] 図の主題が1つで、ノードが過密ではない。
- [ ] 本文と図の内容が一致している。
- [ ] コードブロックの構文を確認している。
- [ ] 対応する図種ではアクセシビリティ説明を付けている。

## 既存文書の編集

- [ ] 章の順序変更を検討した。
- [ ] 重複の削除または統合を検討した。
- [ ] 古い情報と根拠のない断定を確認した。
- [ ] 重要な警告、制約、復旧方法を残した。
- [ ] 変更内容と未解決点を別途報告した。

## 最終報告

必要に応じて次を簡潔に示す。

- 主な読者
- 選んだ文書型
- 使用した参照元
- 変更した構成
- 未確認事項
