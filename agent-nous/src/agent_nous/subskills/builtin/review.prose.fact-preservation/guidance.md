# Japanese Fact Preservation

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

日本語を直す際に、数値、日付、固有名詞、条件、責任主体、技術用語、引用の意味が変わっていないかを確認する。

## 判定規則

読みやすい言い換えをしても、根拠のない補足・断定・主語の変更を加えない。
