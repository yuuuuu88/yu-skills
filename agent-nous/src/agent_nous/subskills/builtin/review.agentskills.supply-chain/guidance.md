# Skill Supply-Chain Review

このガイダンスは公開仕様・実践知をNous向けに独立再設計したもの。外部skillの本文、script、server、installerは同梱しない。

## 運用

source、revision、license、script、hook、secret、network、MCP要求を検査し、出所不明の実行面を取り込まない。

## 判定規則

原文をコピーせず独立guidanceへ再設計したか、更新時にhashとライセンスを再確認できるかを審査する。
