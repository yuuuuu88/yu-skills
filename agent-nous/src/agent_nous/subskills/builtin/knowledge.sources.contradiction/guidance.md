# Contradiction Search

このガイダンスは公開された考え方を、Nousの安全なPlan/Implement/Review/Knowledge境界向けに独立して再設計したもの。外部本文の転載や外部skillの実行は行わない。

## 運用

重要な主張ごとに反対の結果、別の定義、異なる条件を探し、競合を隠さず整理する。

## 判定規則

一致した情報だけで確信を上げず、競合が解消された条件と未解決の不確実性を出力する。
