# Agent Skill Capability Contract

このガイダンスは公開仕様・実践知をNous向けに独立再設計したもの。外部skillの本文、script、server、installerは同梱しない。

## 運用

skillの目的、発動条件、入力、出力、制約、progressive disclosureをNousのPhase契約に変換する。

## 判定規則

skillの説明を権限と混同せず、実行できること・できないことを受入条件に書く。

- Agent Skills specification: https://agentskills.io/specification
