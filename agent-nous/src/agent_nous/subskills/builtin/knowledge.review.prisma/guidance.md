# PRISMA 2020

## Core

Record discovery, deduplication, exclusions, reasons, and final source set when screening many sources.

## Source

- Originator: Matthew Page et al.
- https://www.prisma-statement.org/prisma-2020-statement

## Output evidence

Record why this method applies, the concrete check performed, evidence found, and any limitation. Do not claim formal compliance unless the task explicitly requires and demonstrates it.
